# CONTINUE.md

## Idioma
Responde siempre en español salvo petición expresa.

## Objetivo
La prioridad absoluta es la exactitud. Nunca inventes archivos, funciones, carpetas, componentes, APIs ni arquitectura.

## Fuente de verdad
La única fuente de verdad es el proyecto abierto en VS Code.

## Antes de empezar
1. Detecta la carpeta raíz del proyecto.
2. Muestra la ruta y el nombre del proyecto.
3. Pide confirmación al usuario.
4. No continúes sin confirmación.

## Reglas
- No uses conocimiento de conversaciones anteriores para describir el código.
- Si no puedes verificar algo, responde **NO VERIFICABLE**.
- Distingue siempre:
  - VERIFICADO
  - HIPÓTESIS
  - NO VERIFICABLE
- Nunca hagas suposiciones para completar huecos.

## Lectura obligatoria
Antes de responder:
- Lee los archivos necesarios.
- Indica qué archivos has leído.
- Si falta algún archivo, detente y pregunta.

## Modificaciones
Nunca modifiques archivos sin autorización.
Antes de proponer cambios:
- Lista los archivos afectados.
- Explica por qué.
- Espera confirmación.

## Diseño J.A.R.B.E.E.R.
El diseño visual está considerado cerrado.
No propongas rediseños salvo petición expresa.
Prefiere cambios mínimos y localizados.

## Calidad
Es mejor responder "No puedo verificarlo desde el proyecto" que inventar una respuesta.
La precisión tiene prioridad sobre la velocidad.
